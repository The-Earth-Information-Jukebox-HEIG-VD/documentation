# Roadmap

Future plans and features for Earth Information Jukebox.

---

## Current Status

### Completed (v1.0)

- [x] Core sonification engine
- [x] GISTEMP temperature data integration
- [x] POWER API regional data
- [x] Web Audio playback
- [x] Basic UI with playback controls
- [x] Keyboard navigation
- [x] Screen reader support
- [x] Audio transcript
- [x] Docker deployment
- [x] API documentation
- [x] Multiple instruments (orchestra)

---

## Short Term (Next Release)

- [ ] SVS visualization frame extraction

- [ ] VSCO samples by default

- [ ] Save/load compositions

### Accessibility

## How to Contribute

We welcome contributions in any of these areas:

1. **Pick an item** from the roadmap
2. **Open an issue** to discuss the approach
3. **Submit a PR** with your implementation

See the [Contributing Guide](../developer-guide/contributing.md) for details.

---

## Priorities

We prioritize features based on:

1. **Accessibility impact**: Does this help visually impaired users?
2. **User demand**: Is this frequently requested?
3. **Feasibility**: Can we implement this well?
4. **Alignment**: Does this fit the project mission?
